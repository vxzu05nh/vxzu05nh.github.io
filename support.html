PDB Reader 技术支持

最后更新：2026-10-27 · 适用于 PDB Reader（app.pdb.reader）

PDB Reader 是一款阅读 PDB 文档的本地阅读器：没有账号、没有联网服务，文档和你的阅读记录都只存在你自己的设备上。下面是一些常见问题；如果这里没有覆盖到，欢迎写信给我们。

反馈邮箱：vxzu05nh@outlook.com

1. 这是什么应用，支持哪些文档

PDB Reader 专门阅读 PDB 文档。它能呈现正文、章节结构、内部链接与图片资源，并提供书架、书签、标注和全文搜索。它不是通用电子书阅读器，也不打开 EPUB / PDF / 纯文本等其他格式。

2. 如何导入文档

  • 在应用里点「导入文档」，从系统文件选择器挑选 PDB 文件。
  • 或在其他 App（文件、邮件、聊天）里用「打开方式 / 分享」把 PDB 文件交给 PDB Reader。
  • 导入时文件会被复制到应用私有目录，之后阅读不再依赖原文件；卸载应用会一并删除这些副本。

3. 文档和阅读数据存在哪里

文档副本、书架、书签、标注、上次阅读位置与各项设置都只保存在本机应用沙盒里。应用不联网、不上传，也没有服务器接收这些数据，因此我们无法在设备之间替你同步或恢复——更换设备需要重新导入。

4. 打开文档后提示「部分功能只能有限支持」

少数文档使用了较旧或较少见的特性，PDB Reader 会尽力解析，但受影响的部分可能显示为占位或降级样式。这通常不影响阅读正文。如果某篇文档完全无法阅读，请把文件发给我们（见下方联系方式），我们据此改进兼容性。文档本身不会被上传到任何服务器。

5. 文字显示为乱码

PDB 文档的文本编码以文档自声明为准。当声明缺失或与实际不符时，应用会推测一个编码，并提示你确认是否切换。如果你看到乱码，按提示尝试切换编码即可；若仍不正常，请把文档发给我们排查。

6. 阅读进度或标注不见了

  • 请检查设置中的记忆阅读进度开关是否开启。
  • 清理应用数据或卸载应用会重置阅读状态。
  • 系统存储空间不足时写入可能失败；请确保有可用空间后重试。

7. 如何反馈问题或建议

写信到 vxzu05nh@outlook.com，尽量说明：设备型号与系统版本、应用版本，以及能复现的操作步骤。如果能附上出问题的 PDB 文件会很有帮助——文件只用于排查，不会被公开或分享给第三方。

8. 关于 TestFlight 测试版

测试版的崩溃日志与使用数据由 Apple 依 TestFlight 条款收集，我们只能看到 Apple 提供的崩溃报告与汇总统计。如果你在测试版遇到崩溃，附上 TestFlight 发送给你的崩溃反馈最有助于定位。

PDB Reader — Support

Last updated: 2026-10-27 · Applies to PDB Reader (app.pdb.reader)

PDB Reader is a local reader for PDB documents: no account, no online service, and your documents and reading data stay on your own device. Below are some common questions; if yours is not here, write to us.

Feedback Mail: vxzu05nh@outlook.com

1. What this app is, and which documents it reads

PDB Reader reads PDB documents. It renders body text, chapter structure, in-document links and image resources, with a shelf, bookmarks, annotations and full-text search. It is not a general-purpose e-book reader and does not open EPUB / PDF / plain text or other formats.

2. How to import a document

  • Tap "Import" inside the app and pick a PDB file from the system picker.
  • Or hand a PDB file to PDB Reader via Open With / Share from another app (Files, Mail, a chat app).
  • Importing copies the file into the app's private container, so reading later does not depend on the original; uninstalling the app deletes these copies.

3. Where documents and reading data live

Document copies, the shelf, bookmarks, annotations, last reading position and settings all live only in the app sandbox on this device. The app does not go online or upload anything, and no server receives this data, so we cannot sync or restore it between devices — moving devices means re-importing.

4. "Some features are only partially supported"

A few documents use older or rarer features. PDB Reader parses what it can, but affected parts may appear as placeholders or in a degraded style. This usually does not affect reading the body text. If a document is unreadable, send us the file (see Contact below) so we can improve compatibility. The file is not uploaded to any server.

5. Text appears as garbled characters

A PDB document's text encoding follows its own declaration. When that is missing or wrong, the app guesses an encoding and asks you to confirm whether to switch. If you see garbled text, try the suggested encoding switch; if it stays wrong, send us the document to look at.

6. Reading progress or annotations are gone

  • Check that "Remember reading progress" is turned on in Settings.
  • Clearing app data, or uninstalling the app, resets reading state.
  • Writes can fail when storage is nearly full; free up space and retry.

7. How to report an issue or suggestion

Write to vxzu05nh@outlook.com and, if you can, include: device model and OS version, app version, and steps to reproduce. A PDB file that shows the problem helps a lot — it is used only for investigation and is never published or shared with third parties.

8. About TestFlight beta builds

For beta builds, crash logs and usage data are collected by Apple under its TestFlight terms; we only see the crash reports and aggregate statistics Apple provides. If a beta crashes for you, the crash feedback TestFlight sends you is the most useful thing to attach.
